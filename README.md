# Ghost

Jogo em Jack no qual o jogador Fantasma tenta capturar o jogador Pessoa em um
labirinto. A partida tem limite de tempo: se a Pessoa sobreviver até o fim, ela
vence; se for alcançada, o Fantasma vence.

## Controles

| Jogador | Movimento | Parar |
| --- | --- | --- |
| Fantasma (P1) | Setas do teclado | `.` |
| Pessoa (P2) | `W`, `A`, `S`, `D` | `E` |

Pressione `Esc` para sair da partida.

## Compilar e executar

O projeto foi desenvolvido para a IDE do Nand2Tetris e só é compilado e
executado nesse ambiente. Abra a pasta do projeto na IDE e use as ferramentas
integradas para compilar os arquivos `.jack` e executar o jogo.
